# منصة خدمتي | Khidmati

> خدمتك أقرب وأسهل مع خدمتي.

منصة إلكترونية تسهّل الوصول إلى الخدمات: تعرض الخدمات الرقمية والتصميمية والمنزلية بطريقة منظمة، وتساعد العميل يختار الخدمة المناسبة ويطلبها مباشرة عبر واتساب.

## الصفحات
| الصفحة | الملف | المحتوى |
|---|---|---|
| الرئيسية | `index.html` | الواجهة الترحيبية، أهم الخدمات، لماذا تختار خدمتي، طريقة الاستخدام |
| الخدمات | `services.html` | 3 فئات خدمات، لكل فئة صورة ووصف وخدمات فرعية وزر «اطلب الخدمة» |
| التواصل | `contact.html` | نموذج طلب خدمة يتحقق من البيانات ويفتح واتساب برسالة مرتبة |

## فئات الخدمات
1. **الخدمات الرقمية والتقنية:** المواقع الإلكترونية، الحلول الرقمية، الذكاء الاصطناعي
2. **التصميم والإبداع:** المنشورات والإعلانات، العروض التقديمية، المحتوى البصري على Canva
3. **الخدمات المنزلية:** التنظيف، الصيانة المنزلية، المساعدة المنزلية

## التقنيات
- HTML و CSS و JavaScript (بدون مكتبات أو قواعد بيانات)
- خط Cairo للعربية و Poppins للإنجليزية
- الألوان: كريمي، بيج، زيتوني، أخضر سيج، مشمشي، بني داكن (بدون أزرق)
- حركات وتوهّج: بطاقات طايرة، شريط خدمات متحرك، ضوء يتبع الماوس، حواف مضيئة
- تصميم متجاوب يدعم RTL، وصور WebP خفيفة
